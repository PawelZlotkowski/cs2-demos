Record context queues a player POV clip including the chosen time before and after the decision. Run python tools/record_label_clips.py on the host with Steam, CS2 and configured CS Demo Manager. The Docker app stores and plays the resulting MP4; game capture needs the host's graphics session.

Use a negative offset if the video starts before freeze end. Confirm the selected player's POV and match a visible event to the radar. Saved footage survives reloads and Docker restarts.
