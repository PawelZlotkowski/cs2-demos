# Phase 1 technical references

These documents describe the separately hardened Phase 1 source. They are preserved for evidence and integration guidance, **not** as another current project or backlog.

Start with [PHASE1-RESULTS](PHASE1-RESULTS.md) and [PYTHON-DEPENDENCY-AUDIT](PYTHON-DEPENDENCY-AUDIT.md). Dates and test counts describe the original Phase 1 runs. [APP-REVIEW](APP-REVIEW.md) and [VALIDATION](VALIDATION.md) describe an earlier snapshot; `reproduce_findings.py` is historical reproduction code, not a routine command to run against the current app.

The plans, prompts and `skills/` drafts retain their historical context. Existing Studio skills remain in `.cursor/skills/`; these drafts have not been installed over them. Follow [the current delivery plan](../../planning/FINAL-DELIVERY-PLAN.md) and [integration checklist](../../../integration/phase1/README.md) for present work.

`SOURCE-START-HERE.md`, `DOCKER-SETUP.md` and `ORIGINAL-PACKAGE-MANIFEST.json` belong to the original Phase 1 handoff, not the runnable Studio root. Their setup paths and manifest entries are relative to that original package.
